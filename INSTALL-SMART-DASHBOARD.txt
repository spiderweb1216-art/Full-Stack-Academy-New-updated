  1) admin/css/admin.css   - Academy admins, Branch Heads, Branch Admins,

INSTALLATION
  - Back up the two CSS files in your CURRENT LMS.
  - Extract this ZIP to the project root, keeping directory structure.
  - Replace only those two paths.
  - Refresh with Ctrl+Shift+R to clear cached CSS.

CHANGES

    interface text; smaller numerical stats and more balanced cards.
  * Professional typography/spacing for navigation, tables, forms,
    profile pages, instructors, branch views and shared public course form.
  * Public website styling remains unchanged (student/instructor changes
    are scoped to body[data-mode=dashboard] .dashboard-shell).
  * Brand colors, navigation/sidebar visibility, editor fields, format
    toggles, backend approvals, and business logic are unchanged.
  * Responsive constraints are retained.

COMPATIBILITY

  latest instructor course creation CSS from earlier packages. If you
  have edited the two CSS files since those packages, merge the new
  CSS sections marked 'FSA v125' instead of overwriting your own changes.
