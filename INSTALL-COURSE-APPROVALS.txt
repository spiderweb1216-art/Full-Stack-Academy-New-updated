COURSE AUTHORING & PUBLICATION
-----------------------------
Super Admin / Admin Staff: Academy-wide creation and management.
Branch Head / Branch Admin: Create public or private courses for own branch;
  may edit courses owned by that branch. Existing permission limits on other
  features are retained.
Instructor: Create public course drafts using the EXACT SAME editor layout.
  Newly created instructor public courses are status=draft and sent to the
  branch Approvals queue, including central staff. They cannot go live
  until Branch Head, Branch Admin, Admin Staff or Super Admin approves.
  Rejected drafts can be edited and resubmitted. To prevent bypassing review,
  an instructor cannot change a course after its initial public approval
  through this general course editor. Existing instructor private content
  submission/review logic is retained.

'Private course' visibility hides the course from the public catalogue and
public checkout. Assigned student access can still be managed by staff.
These are separate from a published course's protected/private lesson pages.

NOTIFICATIONS
-------------
Topbar bell opens a dropdown. Approvals menu and bell get numeric badges.
Pending instructor-created public courses, instructor private content,
profile/certificate requests, and manual enrollment reviews appear in the
Approvals section, within the user's branch or academy-wide as permitted.
New enrollments, student registrations, central orders, and new enquiries are also
shown as notification messages to the authorized roles. Informational
notifications become read when clicked; unresolved approvals remain counted.
The client refreshes approximately every 45 seconds while the page is open.

Enrollment approvals protect payment: UNPAID purchased enrollments cannot be
approved through the new Approval Centre. Staff must confirm paid orders in
Orders using the existing payment flow. Manually created pending access
requests (or already-paid exceptions) are eligible for approval.
